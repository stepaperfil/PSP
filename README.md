## Лаборатоная работа 1 — Калькулятор HTML + CSS

Калькулятор в стиле Банк Точка. Вёрстка на чистом HTML и CSS. Цвета и шрифт сняты с сайта tochka.com через инспектор браузера. Реализованы hover и active эффекты на кнопках.

**Ветка:** [LAB_1](../../tree/LAB_1)

---

## Лабораторная работа 2 — Калькулятор JavaScript

Добавлена логика калькулятора на JavaScript: обработка событий, вычисление выражений. Индивидуальная операция — кнопка `000` для быстрого ввода круглых сумм (актуально для банковской темы).

**Ветка:** [LAB_2](../../tree/LAB_2)

---

## Лабораторная работа 3 + ДЗ — Интерфейс с карточками, three.js

Компонентный SPA на чистом JS: страница списка акций с фильтрацией и страница «Подробнее». Данные из mock-массива. ДЗ: функции работы с коллекциями (`fill`, `isEqualObj`, `canBeRearranged`) и 3D-модель банковской карты через three.js на странице «Подробнее».

**Ветка:** [LAB_3](../../tree/LAB_3)

---

## Лабораторная работа 4 — REST API на Node.js + Express

Бэкенд на Express с архитектурой MVC. Данные хранятся в JSON-файле. Реализованы 5 методов: список с фильтрацией, получение по ID, создание, редактирование, удаление. Rate limiting через `express-rate-limit`. В эту же ветку добавлен собранный bundle из лабы 6.

**Ветка:** [LAB_4](../../tree/LAB_4)

---

## Лабораторная работа 5 — XHR, AJAX, CORS

Расширение лабы 3: данные загружаются с бэкенда (лаба 4) через XHR-запросы. Добавлены модули `ajax.js` и `stockUrls.js`, компонент фильтрации, страница создания карточки (без сохранения). CORS обходится через расширение CORS Unblock.

**Ветка:** [LAB_5](../../tree/LAB_5)

---

## Лабораторная работа 6 — fetch, async/await, Vite

Замена XHR + колбэков на `fetch` + `async/await`. Добавлена кнопка «Сохранить» с POST-запросом. Фронтенд собирается через Vite и раздаётся с сервера лабы 4 как статика — CORS не нужен, запросы идут на тот же домен.

**Ветка:** [LAB_6](../../tree/LAB_6)
